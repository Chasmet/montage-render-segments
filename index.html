Ce lien GitHub Pages n'est pas l'application

Montage Render Segments

GitHub Pages ne peut pas lancer Node.js, Express ou FFmpeg. Il affiche seulement une page statique.

La vraie application doit être ouverte depuis Render, avec une adresse du type :

https://montage-render-segments.onrender.com

À faire dans Render :

  1. New Web Service
  2. Connecter le dépôt Chasmet/montage-render-segments
  3. Build Command : npm install
  4. Start Command : npm start
  5. Deploy Web Service
Après déploiement Render, tu verras l'upload vidéo et le traitement MP4.
